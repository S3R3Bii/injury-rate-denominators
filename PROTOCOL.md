# Source qualification before injury-rate analysis

31 October 2026 UTC. Independent program Study 16, not a formal-publication manuscript.

## Immediate source gate

Use only the public OSHA Injury Tracking Application Summary Data links at https://www.osha.gov/itadata. Prior ordinary requests for 2024 ZIP and 2025 CSV returned HTTP403. Try the ordinary visible 2025 Summary Data link once through the official browser page. Stop at an access denial or security challenge. Do not obtain case-detail data, worker records, alternate identities, proxies or private exports.

Save the response bytes privately with exact URL, times, size and SHA-256. Do not inspect establishment rows in this source-qualification step. A download by itself is neither source verification nor executed research.

## Analysis boundary

Before inspecting source values, record a specific numerical cohort, source-field contract, denominator/account rules, comparison set and meaningful checks in a later committed protocol revision. Preserve the original proposal and all source failures. Models, selection parameters and held-out evaluation require the program's model-validation standard. No analysis or release is authorized to skip those gates.

Reported summary rates do not establish fault, violations or workplace safety. Establishment identifiers may not reliably identify a physical establishment over time; linking years requires independent identity and attrition evidence. Reporting thresholds and voluntary/nonrequired submissions prevent automatic population generalization.

## Publication

Publish only checked minimal statistical counts and original analysis with OSHA attribution. Keep raw files, establishment names/addresses, source identifiers, personal/worker data and case details private. No employer ranking or individual decision. MIT covers original code, not blanket third-party rights. Separate formal-publication projects including Azure optimization stay private.

## Acceptance criteria

A complete study needs reconciled lawful native source, explicit exposure/missingness accounts, committed methods, independent reconstruction, meaningful boundary tests, reproducible results, clear practical use, readable source-bound figures/manuscript, privacy checks, and exact candidate/main CI/tree/tag proof. Otherwise report the exact incomplete gate. This protocol alone is not a completed study.
